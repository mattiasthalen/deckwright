---
# AC19. Judgement: deckwright says what changed.
type: llm
focus: trace
---

This is the trace of a deck-building interview. The player said: "This deck wants less ramp. Make the ramp target 8." The template's Ramp target was 10. Judge one thing only: the assistant's reply to that.

PASS if the assistant tells the player that Ramp's target is now 8 (in place of 10), in any wording.
FAIL if it changes the target without saying so, says something else changed, or refuses.
